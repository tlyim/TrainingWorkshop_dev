Data Science and AI Tools for Beginners

The problem to solve

  • You have a task that can be automated with code

  • You want to know how an AI assistant can help

Why automation with code?

  • Repetitive tasks can be automated to save time and reduce errors
  • Scalability: Automation allows scaling out in parallel if needed
  • Scheduled tasks can be automated to run at specific times without human attention
  • Judgment-based tasks can be automated with AI acting as your surrogate
  • Complex tasks can be automated by building workflows incrementally, with each step validated before moving on to the next
  • Reproducibility: Automated workflows can be reproduced exactly, verified by others, and shared with others/the future self
Code enables knowledge accumulation and transfer

Automation with code: Examples

  • Structured/Unstructured data collection, such as database queries, web scraping
  • Summarization/Categorization with large language models (LLMs) via API calls
  • Document/Image processing, such as text extraction, color correction, watermarking

Why GitHub, GitHub Codespace, and GitHub Copilot?

Why version control is important

  • Version control (by Git) tracks changes to your code over time

  • To commit changes (i.e., save them for the long term), you must give a commit message to describe the changes made

  • This sets a checkpoint that allows reverting to a previous version of the code,

    • protecting you from losing the original work after failed experimentation or accidental deletion by you or your AI assistant.

Branches of a repo on GitHub

  • Main branch: The default branch of a repo, where the stable version of the code is stored

  • Feature/Development branch: A branch created to develop a new feature or experiment with code changes, without affecting the main branch

Why Python?

Python has become the undisputed industry standard due to an unmatched ecosystem of pre-built tools.

Initially, the scientific and academic computing communities adopted Python for mathematics and research.

As the “Big Data” and AI boom later took off, researchers naturally built their new machine learning tools on top of the Python code they already knew.

Today, because the majority of AI experts use Python, almost all new research papers, tutorials, and corporate APIs are released in Python first,

Week 6 & 7 Key takeaways

  • Data science provides tools and techniques for web scraping, webcrawling, and natural language processing (NLP),
    • allowing collecting and analyzing unstructured data with minimal human intervention
  • The automation pipeline can handle large volumes of data efficiently
    (e.g., multiple years of the S&P 500 companies’ unstructured data),
    • conserving your time, energy, and attention for more value-adding tasks such as
      • learning from each identified page with a high frequency of the matched keywords (e.g., water pollution)

Week 8 & 9 Key takeaways

  • LLMs are powerful tools for a variety of tasks
    • but hallucination is a major risk
  • Techniques such as prompt engineering and grounding can be used to
    • guide LLMs towards more accurate and reliable outputs
  • API access to LLMs enables the automation and scalability
    • required for large volumes of judgment-based analysis tasks, such as financial sentiment analysis

Week 10 Key takeaways

  • No single tool solves every problem
    • Use Python for AI/Machine Learning (ML) tasks, but leverage R for rigorous statistical modeling
    • Selecting the “right tool for the job” is a key skill for data professionals
  • The landscape of data science and AI changes rapidly
    • Continuous self-learning and exploration is the key to always choosing the right tool for the job
